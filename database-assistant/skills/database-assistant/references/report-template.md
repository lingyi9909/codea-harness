# 查询结果模板
- 请求与数据源：
- 时间区间（含左右边界）/时区/过滤条件：
- Schema 来源：真实元数据；推断另列，不混为已验证关系。
- 查询证据：调用 ID、工具动作名、执行时间、脱敏 SQL、错误或行数、是否截断。
- 中文结果表：只展示已批准列，金额保留数据库精度与单位。
- 结论与限制：空结果、返回上限、数据时效、尚未核实的问题。

T2/T3 预留验收格式（尚未启用）：
知识证据 Kxx 含来源及版本；SQL 证据 Qxx 含源及时间；假设 Hxx 引用 K/Q，状态为支持/排除/待验证。
统计明确去重键及关联基数，先验证一对多连接是否放大金额；比例给分子分母与零分母处理。
根因证据不足必须写“待进一步验证”。不通过增加解释文字掩盖工具失败。
