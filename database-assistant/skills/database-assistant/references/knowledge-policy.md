# TeamAI CLI复用与权限

公司确认现有入口为 `teamai recall "帮我查询数据库"`。本模块复用此位置参数语法，不新增CLI封装、不假定额外参数、项目选择、输出格式或权限接口。安装、登录和知识库访问范围沿用公司现有TeamAI流程，凭据不进入Agent或Skill。

Agent默认仅精确允许四条静态命令，主题与[Skill正文](../SKILL.md)逐字对应：通用定位、数据字典/表关联、指标口径、业务流程/案例。**这是有限范围检索，不保证覆盖公司各业务场景或所有知识库内容。**其余三条是使用同一语法的固定检索主题，尚未在公司CLI实测；不能将语法确认写成检索效果验证。

## 调用与降级

只有明确source、表/字段、无需业务语义的纯技术TECH路径才跳过recall。只知道订单号/业务名称、业务口径统计和排查属于BIZ，本轮首次DBHub调用前先调用最相关的已批准固定recall，最多两次，不把用户文本、SQL、业务ID或查询结果拼入命令。若本轮已有同一授权范围内来源可追溯且仍有效的K证据，可按Skill第0节复用并记录；没有K不能声称做过定位。固定主题不一定召回具体业务答案；不相关结果按缺失处理，不能假装已检索全库。

管理员可在安装时替换默认主题，或增加**有限个经安全审批的业务专属固定完整命令**，逐条指定使用场景及所属知识访问域，并同时修改Agent精确shell白名单与Skill主题映射，保持命令字面值一一对应；逐条复验正例、拼接和参数变形等负例。未被两处同步列入的主题不得调用。此项是部署时静态配置，不允许用户文本/SQL/业务ID动态构造命令；不得改为`teamai *`、`teamai recall *`或开放解释器。未验证CLI环境时可删除四条shell allow，保留数据库功能，涉及未知口径的请求澄清后继续。

每次知识记K编号、返回中真实存在的来源/标题、日期或版本及适用范围。未提供来源就标未核实；不自行补链接。将知识表列与真实Schema比对，冲突时报告旧规则并继续确认语义。历史案例只能产生假设。CLI不可用、拒绝、截断或无命中不能导致扩大Shell权限或读取缓存；普通查询继续，统计/排查仅推进不依赖缺失知识的部分。

## 定位能力、支持范围与扩展评估

- 当前四个固定主题：通用查询、数据字典/关联、指标口径、业务流程/历史案例。字面命令均不包含用户具体业务名称/ID，**只能请求广义资料，不能保证命中“业务→项目→source→表”定位链**；真实召回质量、来源是否可追溯以及覆盖哪些项目必须内网逐主题测试，不能用命令语法可执行代替检索效果PASS。
- 管理员按业务域维护“批准范围→固定主题完整命令→TeamAI知识源→实际可覆盖的项目/source/表/规则→验证记录”的对应清单；未批准或未命中即不支持该业务的自动定位。只允许有限个静态、精确许可的完整命令并与Skill映射逐字一致，绝不根据用户输入构造动态命令。
- 若现有TeamAI真实提供原生结构化/受控检索能力，须由管理员取得CLI或SDK/插件官方能力说明，核对只读权限、参数白名单、查询域隔离、来源元数据、Windows执行边界与审计；在这些证据出现前保持“未确认”，本轮**不引入新接口、新MCP或任意Shell**，另行审批后再评估后续版本。
- TeamAI返回旧表名/不一致source时停止引用旧映射，C阶段search_objects为真实结构依据；未知项目或source且无显式授权源/表时止于B，不得以枚举其它source弥补召回。

## 权限边界及部署前检查

OpenCode V2对shell解析出的命令资源匹配permissions；这里只使用无通配符的固定字面值。该配置不是独立OS沙箱，也不保证所有Windows命令解释器具有相同解析行为。

管理员必须确认实际Windows shell/命令扫描、可信teamai可执行文件及PATH/别名，不从用户可写目录加载同名程序；核实CLI只读recall行为和知识库访问域。Agent没有修改PATH、登录、上传、push、任意文件读取或子Shell权限。既有主Agent只允许安全委派，不能直接Shell绕过。

使用现有权限诊断工具测试：四条完整命令、改动参数、附加选项、分号/&&/管道/重定向、反引号/命令替换、环境赋值、换行拼接、解释器包装。测试程序只能为隔离环境中的无害探针。对包含未批准操作的输入，需证明在派发前拒绝且探针未执行；不能只观察模型口头拒绝。纯静态白名单检查不等于这些测试已通过。

如果实装版本无法可靠限制命令，删除shell allow并禁用Agent自动recall；人工提供来源明确的脱敏知识作为不可信输入继续数据库工作。将自动知识增强记为PENDING/FAIL并报告兼容缺口，不放开任意Shell或自行新增执行框架。
