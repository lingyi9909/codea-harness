效果图已直接嵌入[详细设计第 7.3 节](../../2026-11-02-code-harness-web-workbench-design.md)。桌面视口 1488 × 1058；报告截图为可正常滚动的完整长页。图片由浏览器渲染捕获，保留全部设计示意标识。

在 GitHub 下载 `preview.html` 后，用本机浏览器打开。无需安装依赖或启动后端。开始、授权、停止、重新运行、展开阅读和追问只改变示例页面，不执行 Git、不调用 OpenCode 或模型。所有仓库、版本、代码、问题和进度都是模拟数据。刷新后恢复初始示例；历史和消息不会持久保存。

验证范围：HTTP 前端原型已通过浏览器主路径与布局检查；单文件导出已检查依赖内联。当前自动化浏览器禁止 `file://` 协议，因此本地双击打开未实测，请在目标浏览器确认。

仅本地原型交互与布局经过验证，不能据此认定公司 Windows/OpenCode/模型已接通。正式实现仍按设计中的范围、幂等、事件恢复、权限和成果校验要求开发。

视觉沿用用户提供的工作台演示，首期只开放代码 Review。图标使用 Phosphor 标准图标；React/React DOM/Phosphor 的许可见 `THIRD-PARTY-NOTICES.txt`。
